# Аудит пользователей ИБ (1С:Предприятие 8)

Внешняя обработка для 1С:Предприятие 8.3. Показывает пользователей информационной базы и учётные записи с повышенным риском: администраторов, пользователей с пустым паролем, отключенных. Результат можно выгрузить в PDF, CSV, XLS или XLSX.

## Скачать

[AuditUsersIB.zip](AuditUsersIB.zip): в архиве готовая обработка `АудитПользователейИБ.epf`.

## Возможности

**Две таблицы на форме:**

| Таблица | Столбцы |
|---|---|
| Активные пользователи | Имя для входа, Администратор, Пустой пароль, Скрыт, ОС, Последний вход |
| Отключенные пользователи | Имя для входа, Пустой пароль, Последний вход |

- **Администратор**: у пользователя есть роль `ПолныеПрава`.
- **Пустой пароль**: пароль не установлен.
- **Скрыт**: пользователь скрыт из списка выбора при входе в программу.
- **ОС**: включена аутентификация операционной системы.
- **Отключенный пользователь**: выключены и аутентификация 1С:Предприятия, и аутентификация ОС.

Таблицы открыты только для просмотра. Строки можно выделять, искать по ним и копировать.

**Дата последнего входа.** Заполняется по кнопке «Даты последнего входа» из журнала регистрации (событие «Сеанс. Аутентификация»), глубина поиска 1 год. Журнал читается окнами: неделя, месяц, год. Старые записи читаются только для тех пользователей, которые давно не входили, поэтому даже на большом журнале опрос идёт быстро. Пользователи сопоставляются по идентификатору, так что вход под прежним именем после переименования тоже находится.

**Экспорт.** Кнопка «Экспорт» выгружает отображаемые данные средствами платформы:

- **PDF, XLS, XLSX.** Строки активных пользователей окрашены по степени риска:

  | Цвет | Значение |
  |---|---|
  | `#FF0000` | Администратор с пустым паролем |
  | `#D2691E` | Пустой пароль |
  | `#F0E68C` | Администратор |

  Отключенные пользователи не окрашиваются. В PDF под заголовком «Активные пользователи» выводится легенда, в которой только те цвета, что реально есть в таблице.
- **CSV.** UTF-8, разделитель `;`, без раскраски.

**Справочник пользователей.** Кнопка с человечком справа от «Даты последнего входа» открывает справочник «Пользователи». Она есть только в конфигурациях на БСП и только у тех, кому разрешён просмотр справочника, в остальных случаях кнопка скрыта.

## Требования

- 1С:Предприятие 8.3, управляемое приложение. Собрано и проверено на платформе 8.3.25.
- Права администратора информационной базы: без них платформа не отдаёт список пользователей и журнал регистрации.
- Журнал регистрации нужен только для дат последнего входа. Если он отключён или недоступен, остальные данные всё равно показываются.

## Как пользоваться

1. Распакуйте `AuditUsersIB.zip`.
2. В 1С: **Файл → Открыть…** и выберите `АудитПользователейИБ.epf`.
3. Список пользователей заполняется сразу при открытии. Чтобы подтянуть даты входа, нажмите «Даты последнего входа».
4. Чтобы сохранить отчёт, нажмите «Экспорт» и выберите формат.
